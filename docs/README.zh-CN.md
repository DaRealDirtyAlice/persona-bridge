# PersonaBridge

**面向中国留学生的人格保真 LinkedIn Networking 框架。**

> 先明确为什么要认识一个人，再决定认识谁；先保留自己的表达，再使用 AI；先建立真实关系，再考虑机会。

## 项目目的

很多中国留学生把主要精力放在简历、海投、技术题、面试和证书上，却缺少 professional networking 的意识与经验。因此，他们可能错过职位描述之外的行业信息、团队需求、职业路径、技能建议和潜在机会。

PersonaBridge 不提供群发 Bot，而是分享一套方法论和多 Agent 参考架构，帮助学生：

- 明确每轮 networking 的真实目的；
- 在 LinkedIn 上寻找合适的人；
- 使用具体、低压力的理由发起交流；
- 在 AI 辅助下仍然保留本人的表达方式；
- 合理跟进并长期维护职业关系；
- 保存、审查和复盘每轮结果。

## 核心思路

### 1. 先蒸馏自己，再让 AI 辅助沟通

通用 AI 生成的 invitation note 往往过度正式、空泛且高度相似。本框架首先建立独立的 Persona Layer，记录用户真实的表达节奏、正式程度、提问方式、语言质感和沟通边界。

可以使用开源的 [dot-skill](https://github.com/titanwings/colleague-skill) 完成人格蒸馏。生成的私人 Persona 和原始聊天、邮件、访谈材料不应公开。

```text
私人 Persona + 本轮目标 + 经验证的联系人背景
                         ↓
                  个性化消息草稿
                         ↓
                    审查与人工批准
```

目标不是隐藏 AI，而是避免 AI 把不同的人改写成同一种标准化表达。

### 2. 扩列前先明确目的

Connection 数量本身不等于有效的职业网络。每轮任务应根据目标设计人物权重，例如：

| 目标类别 | 示例权重 | 主要目的 |
|---|---:|---|
| 同校校友 | 30% | 降低首次沟通门槛 |
| 相似背景从业者 | 25% | 学习可复制的职业路径 |
| Senior 从业者 | 20% | 获取技能和行业建议 |
| 目标公司员工 | 15% | 了解团队和公司情况 |
| Hiring Manager | 10% | 了解岗位需求，而不是直接索取工作 |

权重需要根据求职阶段、行业、地区和现有网络调整。

### 3. 把 networking 当作关系维护

系统记录联系人为什么被选中、已经交流过什么、当前对话阶段、何时适合跟进，以及哪些动作必须人工审批，从而减少重复联系、重复提问、过早索取 referral 和不必要的追发。

### 4. 保存与复盘每轮结果

参考实现使用本地 Excel 作为轻量 CRM。其他人也可以选择 Google Sheets、Airtable、Notion 或数据库。关键不是使用哪一种工具，而是建立可追踪、可恢复、可复盘的 shared state。

## 三 Agent 架构

- **Executor Agent：** 搜索候选人、核对相关性、提取个性化证据并起草低风险消息。
- **Auditor Agent：** 独立检查身份、证据、重复项、Persona 一致性、目标人物权重和权限边界。
- **Conversation Maintenance Agent：** 管理对话阶段、上下文摘要、等待周期、自然结束和敏感消息升级。
- **Main Orchestrator：** 定义每轮目标、控制批次、协调三个 Agent、执行质量门并同步 CRM。

完整说明见 [ARCHITECTURE.md](ARCHITECTURE.md)。

## 人工审批边界

AI 可以辅助搜索、筛选、总结、起草、审查和提醒，但以下行为必须由用户明确批准：

- 发送简历或个人信息；
- 请求工作、referral、会议或承诺；
- 回复敏感或含义不明确的内容；
- 联系人身份或上下文无法确认时继续行动。

## 项目边界

本项目不是 LinkedIn 群发工具、Connection 增长器、自动索取 referral 的 Bot，也不保证获得工作。用户应保护个人数据，并遵守 LinkedIn 条款和适用法律。
